# قطرات الندى لأنظمة معالجة المياه 💧

متجر إلكتروني عربي لفلاتر ومعالجة المياه بنفس تقسيمة وتجربة موقع egyptfilters.eg، مع **لوحة تحكم كاملة**.
الألوان مأخوذة من اللوجو: النيلي `#2B04B5` والسماوي `#25C8FF`.

مكتوب بـ **PHP 8.1+ و SQLite** من غير أي مكتبات خارجية، فيشتغل على أي استضافة عادية (cPanel / Hostinger / VPS).

---

## التشغيل على جهازك

```bash
php -S localhost:8000 -t public public/index.php
```

| الصفحة | الرابط |
|---|---|
| الموقع | http://localhost:8000 |
| لوحة التحكم | http://localhost:8000/admin |

**بيانات الدخول الافتراضية للوحة التحكم:** `admin` / `admin123` — ⚠️ غيّرها فوراً من «المديرين».

قاعدة البيانات بتتعمل لوحدها أول ما تفتح الموقع (`storage/database.sqlite`) وفيها بيانات مبدئية (أقسام، منتجات، ماركات، بانرات، مقالات، صفحات) تقدر تعدلها أو تمسحها.

## الموقع

- **الهيدر:** اللوجو، «التوصيل إلى: اختر موقعك» (اختيار المحافظة)، بحث، حسابي، المفضلة، السلة — وشريط قائمة: كل المنتجات (قائمة كبيرة بالأقسام الفرعية)، تخفيضات، خدماتنا، طلب خدمة، المدونة، اتصل بنا، التقسيط.
- **رسالة ترحيب** أول زيارة بس (بتتقفل وتتعدل من الإعدادات).
- **الرئيسية:** سلايدر ← أفضل التصنيفات (دواير) ← منتجات مميزة ← بانر عروض بعداد تنازلي ← 3 بانرات ← الأكثر مبيعاً ← المنتجات الجديدة ← بانر التقسيط ← أقسام فرعية ← بانر ماركة ← تسوق حسب الماركة ← بانرين (صيانة / تقسيط) ← أحدث المقالات ← نبذة وأرقام.
- **كارت المنتج:** صورة بإطار، مفضلة ♡، زر + للسلة، التقييم، السعر والخصم، سطر ميزة (قسط شهري / ضمان / ماركة)، شارة «اكسبريس | بكرة»، و«نفد» للمنتجات الخلصانة.
- **صفحة المنتج:** معرض صور بتكبير، الماركة، التقييم، «وفرت»، صندوق التقسيط، المخزون و«كمية محدودة»، إضافة للسلة / شراء الآن، جانب «تواصل مع فريق المبيعات»، شريط شراء ثابت تحت، الوصف والمواصفات، أسئلة شائعة خاصة بالمنتج، تقييمات العملاء، «قد يعجبك أيضاً».
- **كل المنتجات / الأقسام / الماركات / التخفيضات / البحث:** فلترة بالأقسام والأقسام الفرعية (checkboxes)، السعر، المتوفر فقط، وترتيب.
- **السلة والدفع بخطوات:** سلة التسوق ← تفاصيل الشحن ← الدفع والتأكيد (الدفع عند الاستلام أو فودافون كاش / إنستاباي).
- **حساب العميل:** تسجيل برقم الموبايل، طلباتي، إعدادات الحساب، المفضلة.
- **طلب خدمة صيانة / تركيب**، **طلب تقسيط**، **تتبع الطلب**، **المدونة**، **صفحات السياسات**، **اتصل بنا**، **النشرة البريدية**.
- زر واتساب عائم، وشريط سفلي للموبايل (الرئيسية / التصنيفات / حسابي / واتساب).

## لوحة التحكم (`/admin`)

الرئيسية (أرقام + رسم المبيعات) · الطلبات (حالات + طباعة فاتورة + المخزون بيرجع عند الإلغاء) · طلبات التقسيط · طلبات الصيانة · العملاء · رسائل العملاء · المنتجات · الأقسام (رئيسية وفرعية) · الماركات · التقييمات (موافقة قبل الظهور) · السلايدر · البانرات · المدونة · الصفحات · الأسئلة الشائعة · المشتركين (تصدير CSV) · إعدادات الموقع · المديرين.

## الرفع على استضافة

1. ارفع كل ملفات المشروع.
2. **الأفضل:** خلّي جذر الموقع (Document Root) يشاور على فولدر `public`.
   **لو مش هينفع** (زي `public_html` في cPanel): ارفع المشروع كله جوه `public_html`، وملف `.htaccess` الموجود في الجذر هيحوّل كل حاجة لـ `public` ويمنع الوصول لـ `app` و`storage` و`views`.
3. اتأكد إن `storage` و`public/uploads` ليهم صلاحية كتابة (755 أو 775).
4. ادخل `/admin`، غيّر كلمة المرور، وعدّل الإعدادات (التليفون، الواتساب، العنوان...) وارفع صور منتجاتك الحقيقية.

> على Nginx: خلّي `root` يشاور على `public` وضيف `try_files $uri /index.php?$query_string;`

## هيكل المشروع

```
app/            منطق الموقع (قاعدة البيانات، البيانات المبدئية، الدوال، صفحات الموقع ولوحة التحكم)
views/          قوالب الصفحات (site / admin / layouts / partials)
public/         index.php، CSS، JS، الصور، والصور المرفوعة
storage/        قاعدة البيانات SQLite
```

> الماركات وصور المنتجات والمحتوى الموجود أمثلة توضيحية — استبدلها ببياناتك الحقيقية قبل الإطلاق.
