# قطرات الندى لأنظمة معالجة المياه 💧

موقع متجر إلكتروني عربي لفلاتر ومعالجة المياه، مع **لوحة تحكم كاملة**.
الألوان مأخوذة من اللوجو: النيلي `#2B04B5` والسماوي `#25C8FF`.

مكتوب بـ **PHP 8.1+ و SQLite** من غير أي مكتبات خارجية، فيشتغل على أي استضافة عادية (cPanel / Hostinger / VPS).

---

## التشغيل على جهازك

```bash
php -S localhost:8000 -t public public/index.php
```

افتح:

| الصفحة | الرابط |
|---|---|
| الموقع | http://localhost:8000 |
| لوحة التحكم | http://localhost:8000/admin |

**بيانات الدخول الافتراضية:** اسم المستخدم `admin` وكلمة المرور `admin123`.
⚠️ غيّر كلمة المرور فوراً من لوحة التحكم ← المديرين.

قاعدة البيانات بتتعمل لوحدها أول ما تفتح الموقع (`storage/database.sqlite`)، وفيها منتجات وأقسام وبيانات مبدئية تقدر تعدلها أو تمسحها.

## صفحات الموقع

- **الرئيسية:** سلايدر، أقسام المنتجات، الأكثر مبيعاً، بانرات العروض، عروض وخصومات، مراحل التنقية السبعة، ليه تختارنا (أرقام)، أحدث المنتجات، آراء العملاء، الأسئلة الشائعة، وشريط حجز الصيانة.
- **المنتجات / الأقسام / العروض / البحث:** فلترة بالقسم والسعر وترتيب.
- **صفحة المنتج:** معرض صور، خصم، المخزون، الضمان، الكمية، أضف للسلة، اشتري الآن، اطلب على واتساب، الوصف والمواصفات والتوصيل، ومنتجات مشابهة.
- **السلة وإتمام الطلب:** المحافظات المصرية، الدفع عند الاستلام أو فودافون كاش / إنستاباي، وشحن مجاني فوق مبلغ معين.
- **تتبع الطلب:** برقم الطلب ورقم الموبايل.
- **طلب صيانة / تركيب**، **تواصل معنا**، **من نحن**، **الأسئلة الشائعة**.
- أزرار عائمة للواتساب والاتصال، وتصميم متجاوب مع الموبايل.

## لوحة التحكم (`/admin`)

- **الرئيسية:** طلبات اليوم، مبيعات الشهر، الطلبات الجديدة، رسم بياني لمبيعات آخر 14 يوم، حالة الطلبات، الأكثر مبيعاً، تنبيه المخزون القليل.
- **الطلبات:** بحث وفلترة بالحالة، تفاصيل الطلب، تغيير الحالة (المخزون بيرجع تلقائياً عند الإلغاء)، واتساب العميل، وطباعة الفاتورة.
- **المنتجات:** إضافة وتعديل وحذف، رفع صورة رئيسية ومعرض صور، سعر قبل وبعد الخصم، مخزون، شارة، ضمان، وإظهار أو إخفاء وتمييز.
- **الأقسام**، **طلبات الصيانة**، **رسائل العملاء**.
- **محتوى الموقع:** السلايدر، آراء العملاء، الأسئلة الشائعة.
- **الإعدادات:** الاسم، التليفون، الواتساب، الإيميل، العنوان، السوشيال ميديا، مصاريف الشحن، الدفع بالمحفظة، وأرقام "لماذا نحن".
- **المديرين:** تغيير كلمة المرور وإضافة مديرين.

## الرفع على استضافة

1. ارفع كل ملفات المشروع.
2. **الأفضل:** خلّي جذر الموقع (Document Root) يشاور على فولدر `public`.
   **لو مش هينفع** (زي `public_html` في cPanel): ارفع المشروع كله جوه `public_html`، وملف `.htaccess` الموجود في الجذر هيحوّل كل حاجة لـ `public` وهيمنع الوصول لملفات `app` و`storage` و`views`.
3. اتأكد إن فولدر `storage` وفولدر `public/uploads` ليهم صلاحية كتابة (755 أو 775).
4. افتح الموقع، ادخل `/admin`، غيّر كلمة المرور، وبعدين عدّل الإعدادات (رقم التليفون والواتساب والعنوان...).

> على Nginx: خلّي `root` يشاور على `public` وضيف `try_files $uri /index.php?$query_string;`

## هيكل المشروع

```
app/            منطق الموقع (قاعدة البيانات، الدوال، صفحات الموقع ولوحة التحكم)
views/          قوالب الصفحات (site / admin / layouts / partials)
public/         الملفات العامة: index.php، CSS، JS، الصور، والصور المرفوعة
storage/        قاعدة البيانات SQLite
```

أهم الإعدادات الثابتة في `app/config.php`.
